This is the original readme for Loonyland 2, edited to account for differences in the default controls.
And the lack of add-ons that come with the game.

LOONYLAND 2: WINTER WOODS COLLECTOR'S EDITION
Version 1.1CE
Copyright 2006-2007, Hamumu Software

Thanks for collecting the Collector's Edition!  You've got commentary, bonus battles, gallery pictures, bonus campaigns and much more to get to.  But first, here's how you play:

The game will guide you along with handy tips, so read them carefully.  It won't tell you how to use the title screen, however, so let me:

ARROW KEYS (or joystick)     - Move
Z, CTRL (or joystick btn 1)  - Fire/Accept
SHIFT, X (or joystick btn 2) - Jump/Cancel
A, TAB (or joystick btn 3)   - Spells
ESC, Gamepad START	     - Pause
F11			     - Change window size
F10			     - Change pixel blend for larger window sizes

You can configure controls in the options menu.

When you start a new game, you may want to select "Easy" as one of your Modifiers.  There are 3 Modifier slots in each new game, marked Mod1, Mod2, and Mod3.  If you move the cursor down to any of them with the arrow keys and then press left or right, you can choose Modifiers to apply to your game.  Easy will make it easier, which is not a bad idea for your first play!  As you earn Achievements, you'll unlock many more Modifiers which make the game... interesting.

You can also press left or right on the "Go!" button to change which Campaign you are playing.  By default, it is "Original" which is the normal LL2 adventure.  No other campaigns have been included, but it is technically possible that somebody could make one! The "addons" folder has instructions for how to build them, and the instructions have been expanded from the original LL2 addon instructions.

Good luck, and don't forget to read the tips that pop up when you play.  If you miss one or just want to go back and check again, pause the game (by pressing ESC) and select "Tips" from the menu.  You'll be able to re-read any tip you've received.

Thank you for buying my game, and I hope you love it as much as I do.
