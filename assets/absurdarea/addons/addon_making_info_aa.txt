If something you make acts a little wierd, consider what you are working on.  There's a good chance that there is some hard-coded effect involved (for example, if the quest Free Melly is assigned, and Klonk is not yet dead, then map #20 - normally Brisk Bog - will have no enemies on it).

Note that some hardcoded stuff is different in Absurd Area! Especially, quest related things.

When making your own adventures, you need to copy that format EXACTLY.  Note that the first line of the file is the name of the adventure.  On each line after that, the first number/word is the type of level it is:
0 - a regular area, presumably with monsters
LF_TOWN - town.  The player resurrects at the last one of these he visited when killed.  Also, magic and stamina regenerate twice as fast here.
LF_ARENA - an arena match.  This affects some game rules.  Arena matches take place in the specific 5 levels that are marked LF_ARENA already, so you must leave them in those spots.  Things will be strangely messed up if you include the arena without doing that.  If you're not including the arena, don't worry about it, and don't use the LF_ARENA level type.  Just make sure Tina Tsarina isn't in your game!

The block of 5 numbers/words after that are the 5 monster types that appear randomly in this level.  From left to right they are increasingly more rare/less likely to appear.  These monster names come from the list above, make sure you enter them exactly as written!

After that comes a number indicating how many monsters to put in the level.  There can't be more than around 220 monsters, including ones that were placed in the level in the editor.

The next block of numbers are the herb and mining counts.  The first 6 numbers are how many of each type of herb should appear (in alphabetical order), and the last number is how many mining cracks should appear.  What the game actually does is randomly pick from 0 to the number given, so a higher number just means it's more likely to be higher, rather than guaranteeing more.  Note that herbs have rules on where they grow, so for example, Bubbleweed won't be put in the level at all unless there is riverside terrain.

The next thing is of course which song to play!  All 16 song slots are filled in Absurd Area, so you will have to replace the songs if you want custom songs. Custom songs have to be OGG files, put in the music folder, with the same naming convention as the existing songs - "aasongXXX.ogg", where XXX is a 3-digit number.  So instead of putting SONG_BOSSFIGHT, you might put 6, to play your own custom song that you saved as aasong006.ogg. (But, SONG_BOSSFIGHT will still link to song number 6. Keep track of whichever makes it less confusing for you.)

And lastly, you can put anything you want on the end (or nothing), but it's wise to do what I have done.  Put in a comment, so you know which level it's referring to.  Even smarter to put in a level number in your comment to help you keep track.

If you don't provide enough lines in your TXT file for all of your levels, it will automatically fill the missing spots with the original values.

A trick: start a character in your new game (or if you have one already, play that character), and then exit immediately back to the title screen.  At the top of the title screen, it will print out the first error it found in your TXT file, and which line it's on.  If there's nothing there, then you have no errors!  Of course, your actual adventure might have all kinds of problems, but at least you didn't screw up the text file.

Here are all the editor keyboard commands! Some of these are kinda weird. Also! Make sure you don't accidentally press Esc one too many times when closing a menu, or it will close the editor without saving or confirming!

f: file menu
m: Shows the map (New to AA! Click on the map, or use the arrow keys, to move around the level. ESC to exit.
spacebar: Cycles through the various plop modes
b: Increase brush size
+/-: change floor tile selected
o/p: change wall ceiling selected
[/]: change wall wall selected
,/.: change current item selected
backspace: Delete everything on the moused over tile
ADWX: Resize the level (D/X increase size right/down, A/W decrease size left/up)
IJKM: Shift all the contents of the level up/left/right/down
T: Toggle whether tags are drawn
t: tag tile with selected tag
Y: OK, this one I added for AA. It's kinda weird. First, select an item. Then, mouse over a tile with a tag. Then, press Y. All squares with that tag will be scanned; if they don't have an item or a wall, they will be plopped with the selected item.
y: Another AA add. This will also scan over all tiles with the same tag as you are mousing over, but it will tag all those tiles with the selected tag.
u: Super weird AA add. This will look at the tag you have selected, count the number of tiles with that tag, and change your selected tag to be equal to that count (maxed at 255). This is a really weird, but quick, way to count how many tiles you have tagged with a specific tag.
;/': Change selected tag
:/": Change selected tag by 10 (AA add)
c: Copy the selected area
v: Paste the selected area centered on the mouse position. Note that this will copy monsters! It is possible to stack multiple monsters in the same tile with this feature.
r: Random plop mode
g: "Get" the floor, wall, or item under the cursor
C: Set the entire map to the same brightness as the moused over tile.
s: If you are in Light mode, and the selected tag is 0-16, this sets the moused over area (including brushsize) to light equal to the selected tag. If you are in Dark mode, and the selected tag is 0-32, this will set the area's light to negative the selected tag. AA addition!
Q: "Cavernize," which randomly scrambles certain wall tiles, and the floors and holes in the floor in the Underworld.
q: Cavernize, but specifically for the dark floors and pits from the Glacial Gorge. AA add (it was in the original program but disabled, I put it back in)
!: Scans the entire world for presents and chests. The location with the .exe will have a text file, "blah.txt", detailing if any presents/chests are missing or occur multiple times.
?: AA add. Scans the entire world for GoToMap specials. The file "lmao.txt" will detail, for each level, all of the specials leading in or out.
F: AA add. Scans the entire world to see if the selected floor tile is ever used for any purpose, and tells you exactly where. The file "rofl.txt" will detail which level and the exact location the tiles was used as a floor, any part of a wall, or even created as part of specials. Use it if you suspect that you may have an "extra" tile that you never used anywhere. If the output file is blank, then you never used it (unless you had another tile change to the tile in question, which the code doesn't check for)
G: AA add. Scans the current map for all tiles that are tagged with the selected tag. The file "ooloo.txt" will detail exactly where they all are, and give a count. If it is empty, you know you haven't used the tag in this level. Useful if you want to summon monsters or change tiles on a tag, and don't want to accidentally break your specials by using the same tag for 2 things!
n: AA add. Scans the current level for mushroom items, and generates a soft glow of light around them all. I used this because I like how the mushroom glow now looks kinda circular.
N: AA add. Complicated green crystal specials I put in just for the Crystal Caves. Don't use unless you want basically exactly the same effect I used in the Crystal Caves, which will require a bit of research. Scans the map for green crystals, changes the floor under them, adds specials, a bunch of other stuff. I designed this effect to be used exactly once ever.
h: AA add. Another thing designed to be used once. You know the hidden walls maze in Frostburn's castle? This code scans the map for any tiles tagged exactly 250, then places a special there that, when the tile is stepped on or shot, copies from the specific location 59,70 to this tile. Very esoteric. You will probably not want to use this.

Some of those should obviously never be messed with (do NOT touch the VAR_CONTROLS stuff!).  There are also tons more variables you may use for your own purposes.  They're saved and kept throughout the adventure.  These are variables numbered from 516 to 900.  A variable can hold values from 0 to 255, though almost always they are just either 0 or 1.  Setting some variables has a side effect.  For example, if you set a QUESTASSIGN variable, it makes the "NEW QUEST" box pop down and the sound play.  If you set a QUESTDONE variable, it not only pops up the "QUEST COMPLETE" box and makes the sound, but also automatically marks the quest assigned and gives you 100xp (1000xp in madcap).

You are welcome to mark quests assigned or completed any time you want by setting the appropriate variables.  As an example, variable 55 is the one to set to 1 if you want to mark the sixth quest done (it's the 6th quest since quests start at #0, not #1).  The quests are:

Tags are an important concept.  Press ; and ' to cycle the tag number in the editor, and press T to tag the tile the cursor is on.  As it says above, tagging a villager specifies which villager it is (if you leave that map and return, you can see the villager in its new form, so you can make sure you got the right one).  Other uses for tags:

- A special can check to see if all monsters with a certain tag have been killed (monsters take on the tag of the space they were placed on)
- You can use it as a location for some things in specials
- a tag of 255 is impassible to monsters (not Loony)
- a tag of 254 is impassible to evil monsters
- tag potential rope bridge spots to indicate which bridge it is (there can be 8 of them, tagged 0-7).  Note that rope bridges only work if they are the right width apart, and both stumps are tagged the same.
- same for choppable trees and sound crystal barriers (check the var list to see how many there can be)
- for the Great Guru, tag him 12 (that's his villager number), then tag the space below him with which talent he should carry
- tag skill scrolls with which skill to give
- tag presents 0-98 to indicate which one they are
- tag chests to indicate their number (0-49).  It doesn't matter which type they are, though I made 10 of each type in increasing order of quality.
- a monster tagged 255 (happens automatically) is worth no XP or items.  Ones made by other monsters get this tag
- a monster tagged 254 gives XP but no money or items. Happens automatically to ghosts created with the Haunted modifier
- tag Titanic Titans to indicate which one they are
- other subtle things I am not remembering.  Look at winter.llw to see tags in use in every possible way, or madness.llw for simpler examples (the Choose Your Class level uses tags to specify where items should appear in a special, and several other uses)
- AA add: most collectible items tagged 200 or higher will not trigger Tracking. You can use this to mark items that are just for display, in unobtainable areas.
- AA add: a notable exception is the two Supplies items, which will not trigger Tracking if they have a tag 50 or higher. The Supplies items will disappear on map load if you have the quest completed; therefore, if you want to use them as cosmetics you will have to summon them with specials, and will probably want to use tags. But, then you don't want Tracking to trigger. Have fun.
